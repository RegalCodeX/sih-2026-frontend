# SIH 2026 - Travel & Tourism

Frontend developed for our **Smart India Hackathon (SIH) 2026** project under the **Travel & Tourism** theme.

## 📌 About

This project is a frontend interface designed to provide a modern and user-friendly experience for travelers and tourists.

The interface focuses on making travel planning, destination discovery, and tourism-related information easier to access.

## ✨ Features

- Modern and responsive UI
- Travel-focused interface
- Destination exploration
- User-friendly navigation
- Interactive frontend components
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
